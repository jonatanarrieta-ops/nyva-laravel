NYVA: plataforma web para la gestión de establecimientos, productos y pedidos

Proyecto de la asignatura Electiva Profesional II

Introducción

El presente proyecto propone el desarrollo de NYVA, una plataforma web orientada a la gestión de establecimientos comerciales, productos y pedidos. La aplicación busca centralizar y optimizar los procesos relacionados con la administración de establecimientos, organización de catálogos, registro y seguimiento de pedidos, permitiendo mejorar el control de la información y facilitar la toma de decisiones mediante herramientas tecnológicas.

Objetivo general

Desarrollar una plataforma web para la gestión de establecimientos, productos y pedidos, orientada a la optimización de los procesos administrativos y al seguimiento de las ventas mediante herramientas tecnológicas.

Objetivos específicos

  1. Analizar los requerimientos funcionales y no funcionales relacionados con la gestión de establecimientos, productos y pedidos.
  2. Diseñar la estructura de la plataforma y la base de datos.
  3. Desarrollar los módulos de establecimientos, categorías, productos y pedidos.
  4. Implementar un panel de indicadores y un módulo de reportes.
  5. Realizar pruebas funcionales para validar el funcionamiento de la plataforma.

Estado del arte

Para el desarrollo de NYVA se tomaron como referencia diferentes soluciones de gestión comercial y plataformas web orientadas a la administración de productos y pedidos. Estas referencias permitieron identificar características relacionadas con la organización de catálogos, registro de pedidos, seguimiento de estados e indicadores de ventas. A partir de estas referencias se planteó una solución adaptada a las necesidades de gestión establecidas para el proyecto.

Justificación

NYVA busca mejorar la organización y el control de los procesos administrativos relacionados con establecimientos, productos y pedidos mediante una plataforma centralizada. La solución facilita el registro y consulta de información, el seguimiento de los pedidos y el análisis de las ventas mediante indicadores y reportes, contribuyendo a una gestión más organizada y eficiente.

Metodología

Se utilizó un enfoque de desarrollo iterativo y prototipado, construyendo progresivamente las funcionalidades de la plataforma y realizando validaciones durante cada etapa.

Fase 1Análisis de requerimientos.
Fase 2Diseño de la estructura de datos y de la interfaz.
Fase 3Desarrollo e integración de los módulos.
Fase 4Pruebas, correcciones y validación.

Resultados

Como resultado se obtuvo una plataforma web funcional denominada NYVA, que permite gestionar establecimientos, categorías y productos, así como registrar y administrar pedidos. El sistema incorpora un flujo controlado para los diferentes estados de los pedidos, un panel principal con indicadores de operación y un módulo de reportes que permite consultar las ventas por periodo, los productos más vendidos y el comportamiento de los establecimientos. Además, los clientes pueden consultar el catálogo público, realizar pedidos desde un carrito de compras y hacer seguimiento a su estado.

Conclusiones

El proyecto permitió desarrollar una solución web orientada a mejorar la gestión de establecimientos, productos y pedidos. La integración de los diferentes módulos permitió centralizar la información y facilitar el seguimiento de las operaciones. Además, el desarrollo permitió aplicar conocimientos de ingeniería de sistemas y fortalecer competencias relacionadas con análisis, diseño, desarrollo, pruebas e integración de soluciones de software.
